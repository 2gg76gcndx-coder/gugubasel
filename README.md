# Gugu Basel Family Deals

A mobile-first static website that shares weekly family and children's product deals for Basel and the surrounding area.

## Technologies

- Semantic HTML
- Responsive CSS
- Static assets optimized for Netlify hosting

## Run locally

From the project root, run:

```bash
netlify dev --port 8889
```

Then open `http://localhost:8889` in a browser.

## Project structure

- `index.html` contains the page content and deployed styles.
- `styles.css` contains the standalone stylesheet source.
- `assets/` contains the Gugu Basel logo and product artwork.
